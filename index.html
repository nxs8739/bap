// 02   PURPOSE-BUILT

Everything it needs.
Nothing it doesn't.

A simple file browser and a carefully scoped playback engine—no sprawling menus or unnecessary extras.

MJPEG movie playback

AVI video playback tuned around the tested 320×240, 20 FPS encoding profile.

Long-movie continuation

Sequential AVIX / OpenDML RIFF continuation lets supported long movies keep going.

PCM audio timing

32 kHz, 16-bit PCM with sample-based video timing, independent audio read-ahead and a 20-frame video queue.

SD adapter access

Browse FAT media via SD2SP2 or SD Gecko Slot A or Slot B, all verified on real hardware.

Controller-first browser

Browse directories and AVI files with your GameCube controller. Pause, resume or stop in a few presses.

One standalone DOL

The purple wallpaper is embedded in the executable. No separate PNG or config file required at runtime.

// 03   GET YOUR VIDEO READY

The right format
makes all the difference.

BEANZ AVI Player isn't a universal video player. Convert your media to the tested profile before attempting playback.

Recommended media profile

These are the settings used for successful full-length playback on original hardware.

ContainerAVI (with supported AVIX)
Video codecMJPEG / MJPG
Resolution320 × 240
Frame rate20 FPS
Audio format16-bit PCM, stereo
Audio sample rate32,000 Hz
SD2SP2 testedSD Gecko A & B testedPAL untested

Convert with FFmpeg

Use the v1.3 GitHub README for the automatic single-file and batch conversion commands.

The commands preserve the recommended media profile, fit the video without stretching square-pixel widescreen sources, and verify the video frame and PCM sample counts. For movies with audio, they add silence only as needed to provide a minimum two-second PCM safety margin.

Heads up: MJPEG + uncompressed audio creates large files. Allow space for temporary conversion files and check the FAT32 file size limit. The settings are recommended, not a compatibility guarantee.

ⓘ Before you press play

The project README has the detailed format requirements and the full known-issues list.

  • PAL / 50 Hz hardware: not tested. Verified on NTSC hardware only.
  • SD Gecko Slot A: verified on real hardware, along with Slot B.
  • Known quirks: temporary storage delays may still cause audio gaps or skipped video frames. Use the recommended conversion procedure to avoid premature PCM EOF.
  • Codec limits: H.264, MP3, AAC and arbitrary AVI formats are not supported.
